# Resilient entry, drafts and printing

Goal: implement researched UX improvements for populated qualification forms, reliable local draft recovery, and understandable saved-snapshot printing. User authorizes autonomous implementation, local-only/no GUI. Preserve VMP branding/desktop rail, formulas and original PDF assets.

Architecture: native browser IndexedDB async store, opt-in per authenticated actor+project+system. One recovery slot per system, CAS revision transactions prevent silent multi-tab overwrites. No cloud autosync or service worker; already-loaded page supports offline input, reload/reopen requires verified VMP session/config before recovery. Store raw strings and recordId/version plus selected form/point, no auth tokens/results/PDF. Default off with personal-device explanation; explicit clear/off removes draft. Signout/identity switch clears old actor drafts and disables controller; no promise against browser eviction/shared OS access. Recover only by explicit action, never auto-overwrite entered data; config validation+safe JSON bounds; resumed record retains expected version so server detects conflict. Local snapshot is not a GMP audit record.

Primary owns shared integration/app/gas/controllers sequentially. Read-only specialist audit may independently inspect report correctness/tests without mutations. Independent sol security/concurrency review required at checkpoint before completion.

Existing backend exact snapshot/hash checks remain. Guard unsaved/current-generation print; title and helpful error/status wording. No formula/PDF renderer changes.
5. Populated18form/7width/axe, headless targeted recovery +print tests, targeted unit/session/build/typecheck/budget, screenshot review; independent high-risk review; exact source/dist/HTTP verify. Update state/guide/research report.

Rollback: private resilient-entry snapshot and remove newly added assets+script/style references; no migrations or production writes to roll back. Preserve unrelated pendingrelease files. Failure modes: default-off; if IDB unavailable keep entry and JSON export; if conflict stop autosave and preserve other tab; if session ends hide content as current bootstrap and clear only actor scope. Formal QA validation/UAT remain separate.
